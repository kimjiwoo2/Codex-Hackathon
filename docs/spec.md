# Product Spec — 아이캔(iCan)

> 상태: Draft<br>
> 오너: iCan 해커톤 팀<br>
> 최종 갱신: 2026-08-16

## 1. 문제

아이의 첫 심부름은 이동, 길 찾기, 교통안전, 물건 확인, 귀가가 연속되는 과업이다. 부모는 아이가 어디에 있고 심부름을 잘 수행하고 있는지 계속 확인하기 어렵고, 아이는 복잡한 지도나 긴 문장보다 지금 해야 할 행동을 짧은 음성으로 안내받는 편이 이해하기 쉽다.

아이캔은 부모가 정한 목적지와 물건을 바탕으로 아이의 이동부터 상품 확인과 귀가까지 음성 중심으로 보조하고, 부모에게 현재 위치와 진행 상태를 전달한다.

## 2. 목표

- 부모와 아이가 별도 회원가입 없이 6자리 참여 코드로 같은 심부름에 연결된다.
- 부모가 목적지와 물건을 등록하고 아이의 최신 위치와 진행 상태를 확인한다.
- 아이가 전경 위치 추적과 음성 안내를 통해 마트 이동, 상품 확인, 귀가를 완료한다.
- 실제 GPS가 불안정한 실내 발표에서도 데모 체크포인트로 전체 흐름을 재현한다.
- 상품 사진을 백엔드에서 OpenAI로 판별하되 사진을 저장하지 않는다.

## 3. 비목표

- 회원가입, 로그인, 가족 계정 관리
- 실제 장소 검색 및 상용 도보 길찾기 API 연동
- 앱이 꺼지거나 백그라운드인 동안의 위치 추적
- 푸시 알림, 앱스토어 배포, 운영용 관리자 화면
- AI가 신호나 도로 상황을 보고 횡단 가능 여부를 보장하는 기능
- 실제 아동 개인정보를 사용하는 운영 서비스 출시

## 4. 대상 사용자와 핵심 시나리오

| 사용자 | 상황 | 기대 결과 |
| --- | --- | --- |
| 부모 | 아이에게 첫 심부름을 부탁한다 | 목적지와 물건을 등록하고 참여 코드와 아이의 진행 상태를 확인한다 |
| 아이 | 부모가 만든 심부름에 참여한다 | 짧은 음성 안내를 따라 이동하고 상품을 확인한 뒤 집으로 돌아온다 |
| 발표자 | 실내에서 해커톤 데모를 진행한다 | 실제 GPS 또는 숨은 데모 조작으로 동일한 상태 흐름을 안정적으로 시연한다 |

## 5. 기능 요구사항

### P0 — 해커톤 MVP

- [ ] 앱 시작 시 부모 또는 아이 역할을 선택할 수 있다.
- [ ] 진행 중인 역할 토큰과 임무가 있으면 해당 화면으로 복구한다.
- [ ] 부모가 데모 목적지, 귀가 지점, 상품과 알림 설정을 등록할 수 있다.
- [ ] 임무 생성 후 30분 동안 유효한 6자리 참여 코드를 표시한다.
- [ ] 아이가 코드로 한 번만 참여하고 별도의 아이 역할 토큰을 발급받는다.
- [ ] 부모가 아이의 최신 위치, 갱신 시각, 임무 상태를 확인한다.
- [ ] 아이 앱이 열린 동안 GPS 위치를 추적하고 최대 3초 간격으로 전송한다.
- [ ] 직진, 방향 전환, 경로 이탈, 횡단보도 주의, 도착을 한국어 음성으로 안내한다.
- [ ] 횡단보도에서는 반드시 멈추고 신호와 주변을 직접 확인하도록 안내한다.
- [ ] 아이가 상품을 촬영하고 `MATCH`, `NO_MATCH`, `UNSURE` 결과를 확인한다.
- [ ] 모든 상품 확인 후 귀가 상태로 전환하고 도착 시 양쪽 화면에 완료를 표시한다.
- [ ] 숨은 데모 조작으로 다음 체크포인트, 경로 이탈, 마트 도착, 귀가를 재현한다.

### P1 — MVP 이후

- [ ] 실제 장소 검색과 도보 경로 API 연동
- [ ] 개발 빌드 기반 백그라운드 위치 추적
- [ ] 경로 이탈과 완료 푸시 알림
- [ ] 운영 환경용 데이터베이스와 데이터 삭제 작업
- [ ] 접근성 및 보호자 동의 절차 고도화

## 6. 안전·개인정보·비기능 요구사항

- 안전: AI는 `건너도 된다`고 말하지 않는다. 횡단보도에서는 멈춤과 직접 확인만 유도한다.
- 전경 제약: 위치 안내 중 아이 앱을 켜 두며 화면이 꺼지지 않도록 유지한다.
- 최소 수집: 위치 이력은 저장하지 않고 최신 좌표만 유지한다.
- 사진 처리: 상품 사진은 서버 메모리에서만 처리하고 응답 후 즉시 폐기한다.
- 아동 보호: 해커톤 데모에서는 실제 아동 개인정보를 사용하지 않는다.
- 보안: 비밀값은 저장소와 앱 번들에 넣지 않고 OpenAI 호출은 백엔드에서만 수행한다.
- 사용성: 아이에게 한 번에 하나의 짧은 행동만 큰 글자와 음성으로 안내한다.
- 복구: 네트워크, 위치, 카메라, AI 오류에 재시도 또는 안전한 대체 안내를 제공한다.
- 동기화: 정상 네트워크에서 아이의 상태와 최신 위치가 부모 화면에 5초 이내 반영된다.

## 7. API 및 데이터 계약

- 단일 계약: [`contracts/mission-api.md`](contracts/mission-api.md)
- 상태: `WAITING → GOING → SHOPPING → RETURNING → COMPLETED`, 별도 종료 상태 `CANCELED`
- 인증: 참여 코드는 최초 참여에만 사용하고 이후 부모·아이 역할별 Bearer 토큰을 사용한다.
- 통신: 프런트엔드는 진행 중 임무를 2초 간격으로 폴링한다.

## 8. 완료 조건

- [ ] 부모 폰에서 임무 생성과 참여 코드 표시가 동작한다.
- [ ] 아이 폰에서 코드 참여 후 부모 폰에 상태가 반영된다.
- [ ] 실제 또는 데모 위치가 부모 지도에 5초 이내 표시된다.
- [ ] 방향·주의 음성과 음성 다시 듣기가 동작한다.
- [ ] 실제 OpenAI 상품 판별의 일치·불일치·불확실 결과를 처리한다.
- [ ] 귀가 전환과 완료가 두 기기에 동일하게 표시된다.
- [ ] TypeScript, ESLint, Expo Doctor 검증을 통과한다.
- [ ] 핵심 규칙의 자동화 테스트와 두 기기 수동 데모 절차가 기록되어 있다.
- [ ] 실행 방법, 환경 변수, 알려진 제약이 각 앱 README에 기록되어 있다.
