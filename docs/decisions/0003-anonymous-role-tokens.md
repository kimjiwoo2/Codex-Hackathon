# 0003. 참여 코드와 익명 역할 토큰

- 상태: Accepted
- 결정일: 2026-08-16
- 결정자: iCan 해커톤 팀

## Context

해커톤 MVP에서 회원가입은 과하지만 부모와 아이 두 기기는 같은 임무를 공유해야 한다. 참여 코드만 계속 인증 수단으로 사용하면 코드를 아는 누구나 아이 위치를 조회할 수 있다.

## Decision

부모가 임무를 만들면 30분 유효한 6자리 참여 코드와 부모 토큰을 발급한다. 아이가 최초 참여하면 코드를 소진하고 별도의 아이 토큰을 발급한다. 이후 API는 역할별 Bearer 토큰으로 권한을 확인하며 앱은 토큰을 SecureStore에 저장한다.

## Alternatives considered

- 회원가입과 가족 계정 — 데모 범위와 구현 시간이 과도하다.
- 참여 코드만 지속 사용 — 코드 노출 시 위치와 임무를 보호할 수 없다.

## Consequences

### Positive

- 로그인 없이도 부모와 아이 권한을 분리할 수 있다.
- 참여 코드 노출 시간을 줄이고 위치 조회 범위를 제한한다.

### Negative / Trade-offs

- 토큰 발급, 저장, 만료와 역할 권한 검사가 추가된다.
- 앱 삭제 후 토큰을 잃으면 진행 중 임무 복구가 어렵다.
