# 0001. Expo 기반 프런트엔드 구성

- 상태: Accepted
- 결정일: 2026-08-16
- 결정자: 개발팀

## Context

`main` 브랜치에 Expo SDK 54 기반 애플리케이션이 추가되었습니다. 저장소는 프런트엔드와 백엔드를 분리하는 구조를 사용하므로 루트에 생성된 앱 파일의 위치와 기술 선택을 명시해야 합니다.

## Decision

- 기존 Expo SDK 54 애플리케이션을 프런트엔드 구현 기반으로 사용합니다.
- 앱 소스, 자산, 패키지 설정과 개발 스크립트를 `frontend/` 아래에 둡니다.
- 저장소 루트에는 공통 설정, 문서, `frontend/`, `backend/` 진입점만 둡니다.
- Expo 관련 구현은 SDK 54에 맞는 버전별 문서를 기준으로 합니다.

## Alternatives considered

- Expo 앱을 저장소 루트에 유지 — 백엔드 추가 시 앱 경계와 패키지 소유권이 불명확해집니다.
- 다른 프런트엔드 스택으로 재초기화 — 이미 생성된 동작 가능한 기반을 버리고 5시간 개발 시간을 소모합니다.

## Consequences

### Positive

- 프런트엔드와 백엔드의 코드 및 의존성 경계가 명확해집니다.
- 기존 Expo 코드를 삭제하거나 다시 생성하지 않고 활용할 수 있습니다.
- 각 애플리케이션을 독립적으로 실행하고 검증할 수 있습니다.

### Negative / Trade-offs

- 프런트엔드 명령은 저장소 루트가 아니라 `frontend/`에서 실행해야 합니다.
- 루트 실행을 원하면 향후 별도의 워크스페이스 스크립트 결정이 필요합니다.
