# 0002. FastAPI 기반 백엔드 모놀리스 구성

- 상태: Accepted
- 결정일: 2026-08-16
- 결정자: 개발팀

## Context

해커톤 데모에 사용할 백엔드는 짧은 시간 안에 HTTP API를 제공하고, 로컬과 CI에서 같은 방식으로 재현 가능해야 합니다. 현재는 분리된 서비스나 데이터베이스가 필요하지 않으며, 개발 환경은 `uv`로 통일하기로 했습니다.

## Decision

- 백엔드는 `backend/` 아래의 FastAPI ASGI 애플리케이션 하나로 구성합니다.
- 의존성, 가상환경, Python 버전, 잠금 파일은 `uv`로 관리합니다.
- 첫 API는 CI와 배포 환경에서 가용성을 검증할 수 있는 `GET /health`로 둡니다.
- GitHub Actions는 백엔드 경로가 변경될 때 포맷 검사, 린트, 테스트를 실행합니다.

## Alternatives considered

- 서비스별 프로젝트 분리 — 데모 단계에서는 배포·관측·계약 관리 비용이 기능 구현 속도를 늦춥니다.
- 프레임워크 없이 표준 라이브러리 HTTP 서버 사용 — API 검증과 문서화, 테스트 도구를 직접 마련해야 합니다.
- 컨테이너 기반 개발 환경 우선 구축 — 현재 요구에는 로컬 실행과 CI에 불필요한 설정을 추가합니다.

## Consequences

### Positive

- 하나의 명령으로 의존성을 동기화하고 서버·테스트를 실행할 수 있습니다.
- FastAPI의 OpenAPI 문서로 데모 API를 빠르게 확인할 수 있습니다.
- 모놀리스 내부에서 기능을 추가하면서도 프런트엔드와의 HTTP 경계를 유지합니다.

### Negative / Trade-offs

- 향후 독립 확장이 필요해지면 서비스 경계와 배포 방식을 다시 결정해야 합니다.
- 현재 상태 확인 API만 제공하므로 제품 기능 API와 데이터 저장소는 별도 작업으로 추가해야 합니다.
