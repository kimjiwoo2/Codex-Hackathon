# 0005. 실제 GPS와 가상 체크포인트 결합

- 상태: Accepted
- 결정일: 2026-08-16
- 결정자: iCan 해커톤 팀

## Context

서비스 핵심은 위치 기반 안내지만 해커톤 발표는 실내에서 진행되어 GPS 품질과 실제 이동 거리를 보장할 수 없다. 가상 이동만 사용하면 위치 기반 기능의 설득력이 낮아진다.

## Decision

아이 기기의 실제 전경 GPS를 기본 입력으로 사용하고, 첫 유효 좌표에 상대적인 데모 경로와 체크포인트를 생성한다. 실내 발표에서는 숨은 데모 조작으로 동일한 상태 reducer에 `DEMO` 위치 이벤트를 주입한다.

## Alternatives considered

- 실외 실제 GPS만 사용 — 실내 발표와 GPS 흔들림에 취약하다.
- 가상 이동만 사용 — 데모는 안정적이지만 실제 위치 추적 검증이 어렵다.
- 실제 길찾기 API — 키, 과금, 장소 검색과 경로 정책까지 범위가 커진다.

## Consequences

### Positive

- 실제 GPS 기능과 안정적인 발표 흐름을 함께 제공한다.
- 데모와 실제 경로 판정이 같은 상태 로직을 사용한다.

### Negative / Trade-offs

- 데모 위치는 실제 길찾기 결과가 아니며 제품 화면에서 구분해야 한다.
- 백그라운드 추적은 Expo Go MVP 범위에서 제외된다.

## Follow-up

- [ ] 실제 GPS와 데모 조작 각각의 두 기기 시나리오를 검증한다.
- [ ] 운영 버전에서 실제 장소·경로 API를 선정한다.
